# About LintDrop / 关于 LintDrop

## 中文

LintDrop 是一款基于 Tauri 2.x 构建的轻量级桌面格式检查器，面向开发者和非技术用户的日常配置文件校验场景。

它支持 JSON、YAML、TOML、XML、CSV、INI、ENV 七种常见配置文件格式。用户可以通过拖拽文件或粘贴内容进行即时校验，工具会以行级精度定位错误并给出中文友好提示，同时提供常见问题的自动修正和 Diff 对比预览。

LintDrop 默认离线运行，不上传文件内容，适合处理本地项目、公司 workspace、外接盘和临时下载目录中的配置文件。

## English

LintDrop is a lightweight desktop format checker built with Tauri 2.x for everyday configuration-file validation.

It supports seven common formats: JSON, YAML, TOML, XML, CSV, INI, and ENV. Users can drag files into the app or paste text for instant validation. LintDrop reports line-level diagnostics, provides friendly Chinese explanations, and can repair common issues with a before/after diff preview.

LintDrop runs offline by default and does not upload file contents, making it suitable for local projects, company workspaces, external drives, and temporary download folders.
