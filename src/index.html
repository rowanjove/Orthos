About LintDrop / 关于 LintDrop

中文

LintDrop 是一款轻量、离线的桌面格式检查器，专注于日常配置文件的快速校验和常见语法问题修复。

支持 JSON、YAML、TOML、XML、CSV、INI、ENV。你可以拖拽文件或粘贴文本，查看行列级错误定位、中文提示、Diff 对比，并按需保存修正结果。

English

LintDrop is a lightweight, offline desktop format checker for quick validation and repair of everyday configuration files.

It supports JSON, YAML, TOML, XML, CSV, INI, and ENV. Drop files or paste text to review line-level diagnostics, compare diffs, and save repaired content when ready.
