关于 LintDrop

中文

LintDrop 只做一件事：帮你尽快确认配置文件能不能解析。

把文件拖进来，或粘贴一段内容；它会指出具体位置，提供安全的修正建议。原文件不会被覆盖。

English

LintDrop answers one practical question: can this configuration be parsed?

Drop a file or paste a snippet to see what needs attention. Your original file stays untouched until you choose to save a fix.
